# Aura Music

A premium, ad-free YouTube Music desktop client with a modern glassmorphism UI.

## Features

- 🎵 Stream music and videos from YouTube
- 🔍 Search songs, artists, albums, and playlists
- ❤️ Save favorites locally (no account required)
- 📚 View listening history
- 👨‍🎤 Artist pages with discography
- 🎛️ Queue management and playback controls
- 🎨 Modern glassmorphism design

## Installation

```bash
# Install dependencies
npm install

# Run in development
npm run dev

# Build for production
npm run build
```

## Tech Stack

- Electron
- React + Vite
- yt-music-api
- yt-dlp
